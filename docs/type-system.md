# VEL 타입 시스템
## 0. 용어
### 0.1. 서수 (Cardinal)
본 문서에서 **서수**(Cardinal, $\mathrm{Card}$)는 최소 원소 $0$, 자연수, 그리고 최대 원소 $\top$ 으로 구성된 타입이다.
$$ \mathrm{Card} := 0 \mid \mathbb{N} \mid \top $$
다음과 같이 순서를 가진다.
$$ 0 < 1 < 2 < \cdots < \top$$

## 1. 타입의 구성
VEL의 모든 객체는 **함수**로 취급한다. 즉 VEL에서 함수는 일급(first-class) 객체다.
$$ X <: A \mapsto B$$

**배열**은 스칼라 타입 $F$가 정해졌을 때, 1개 이상의 서수에 따라 스칼라 값이 정해지는 함수다.
$$ \mathrm{Array}(d_1,d_2,\cdots,d_n,F) := \prod [0,d_i) \mapsto F \quad (d_i<:\mathrm{Card})$$
인덱스가 0부터 시작함에 유의하라. 스칼라 타입 $F$ 에 대해서는 후술한다.

**행렬**은 랭크 2의 배열이다.
$$ \mathrm{Mat}(m,n,F) := \mathrm{Array}(m,n,F)$$

**벡터**는 열벡터로 표현한다.
$$ \mathrm{Vec}(n, F) := \mathrm{Mat}(n, 1, F) $$

**스칼라**는 자신의 타입에 대해 $1 \times 1$ 행렬로 취급한다.
$$ [F]:=\mathrm{Mat}(1,1,F) $$

### 1.1. 스칼라 타입
스칼라 타입은 VEL의 원자적 타입이며, 연산을 결정하는 수학적 체의 역할도 수행한다.
  - Boolean $\mathrm{Bool}$: 부울 대수[^1]
  - Real $\mathrm{Real}$: 실수
  - Complex $\mathrm{Complex}$: 복소수

아래와 같은 자명한 위계를 갖는다.
$$\mathrm{Real} <: \mathrm{Complex}$$
Boolean과 Real 사이에는 명시적인 위계를 갖지 않는다.

### 1.2. 크기가 $\top$인 차원
배열의 각 차원 크기 $d_i$는 서수이므로 $\top$일 수 있다. $\top$은 **컴파일 타임에 크기를 모르는 차원**을 뜻한다. 실제 길이는 실행 시점에 정해진다.

서수의 덧셈과 최댓값은 다음과 같이 확장한다($n$은 자연수).
$$ n + \top = \top + n = \top, \qquad \max(n, \top) = \top $$

크기가 $\top$인 차원에는 다음 규칙을 적용한다.
- **범위 밖 원소는 null이다.** 실제 길이 이상의 인덱스에 있는 원소는 값이 없는 것(null)으로 취급한다.
- **null 원소를 연산에 쓰면 `NullPointerException`이 발생한다.** 크기를 맞추기 위한 별도의 런타임 검사 코드는 생성하지 않는다. 크기 불일치는 이 예외로 드러난다.
- 크기가 $\top$인 차원끼리, 또는 $\top$과 $n$이 원소별로 연산할 때 결과 차원의 크기는 $\top$이다. 실제 길이는 피연산자 길이의 최댓값이다. 짧은 쪽은 범위 밖 원소가 null이 되므로, 길이가 다르면 `NullPointerException`이 발생한다.

크기가 정해진 차원($n$)끼리 맞지 않으면 컴파일 오류다.

### 1.3. 브로드캐스팅
원소별 연산(`+` `-` `.+` `.-` `.*` `./` `.^` `//` `///` `%%` `%%%`)은 MATLAB의 암시적 확장처럼 피연산자의 모양이 달라도 브로드캐스팅한다.

- 스칼라($1 \times 1$)는 다른 피연산자의 모양으로 확장된다.
- 두 배열은 차원별로 비교한다. 랭크가 다르면 짧은 쪽 뒤에 크기 1인 차원을 붙여 맞춘다.
  - 크기가 같으면 그대로 둔다.
  - 한쪽 크기가 **컴파일 타임에 1로 알려져 있으면** 다른 쪽 크기로 확장한다.
  - 그 외에는 1.2절의 규칙을 따른다(크기가 정해져 있으면 컴파일 오류, $\top$이 포함되면 결과 크기 $\top$).
- 크기가 $\top$인 차원은 실행 시점에 길이가 1이더라도 **확장하지 않는다.** 확장 여부는 컴파일 타임에 정해진다.

예: $\mathrm{Vec}(3) + \mathrm{Mat}(1, 4) : \mathrm{Mat}(3, 4)$ (열벡터 + 행벡터), $\mathrm{Mat}(3,4) + [F] : \mathrm{Mat}(3,4)$

행렬 곱 `*`은 브로드캐스팅하지 않는다. $\mathrm{Mat}(m,k) \cdot \mathrm{Mat}(k,n) : \mathrm{Mat}(m,n)$이며, 스칼라와의 곱은 원소별 곱이다.

### 1.4. 연결 (블록 행렬)
행렬 리터럴의 원소는 행렬일 수 있다. `,`는 가로 연결, `;`는 세로 연결이다.
$$ [A, B] : \mathrm{Mat}(a, c + d) \quad (A : \mathrm{Mat}(a, c),\ B : \mathrm{Mat}(a, d)) $$
$$ [A; C] : \mathrm{Mat}(a + b, c) \quad (A : \mathrm{Mat}(a, c),\ C : \mathrm{Mat}(b, c)) $$

따라서 $A : a \times c$, $B : a \times d$, $C : b \times c$, $D : b \times d$에 대해 블록 행렬 $[A, B; C, D]$는 $(a+b) \times (c+d)$ 행렬이다.
- 스칼라는 $1 \times 1$ 행렬이므로 `[1, 2; 3, 4]`는 이 규칙의 특수한 경우다.
- 가로로 연결하는 블록끼리 행 수가, 세로로 연결하는 블록끼리 열 수가 맞아야 한다. 맞는지 판정할 수 없는 $\top$ 차원은 1.2절의 규칙을 따른다.
- 튜플 $(A_1, A_2, \cdots, A_k)$는 세로 연결 $[A_1; A_2; \cdots; A_k]$다. 원소가 스칼라면 열벡터가 된다.
- 원소 해상도는 모든 블록 해상도의 $\sqcup$이다(3.3절).

### 1.5. 불변성
VEL의 모든 값은 **불변**이다. 값을 바꾸는 연산은 없고, 바뀐 새 값을 만들 뿐이다.

인덱스 대입과 부분행렬 대입은 MATLAB과 같이 **복사 후 다시 쓰기**로 정의한다.
$$ \mathbf m[i] = x \quad\equiv\quad \mathbf m \leftarrow \mathbf m' \quad (\mathbf m'[i] = x,\ \text{그 외 원소는 } \mathbf m \text{과 같음}) $$

즉 `m[i] = x`는 `m`을 복사해 원소 하나를 바꾼 새 값을 만들고, 이름 `m`을 그 값에 다시 묶는다. 대입 전 `m`의 값을 가리키던 다른 이름은 영향을 받지 않는다.

```
a = (1, 2, 3)
b = a
b[0] = 9      # b = (9, 2, 3), a는 여전히 (1, 2, 3)
```

이 규칙은 의미를 정의할 뿐이며, 원래 값을 더 이상 아무도 참조하지 않으면 컴파일러는 복사를 생략하고 그 자리에서 고칠 수 있다.

## 2. 해상도 (Resolution)
원소를 표현할 수 있는 범위(range)와 정확도(precision)의 그룹.

프로그래밍 언어, 또는 외부 라이브러리와의 추상/구체화를 위해 둔다.
  - Boolean: Boolean Literal $\langle\mathrm{Bool}\rangle$
  - Real, Complex
    - Signed $n$-bit Integer $\langle\mathbb K\rangle_{Z}(n)$
    - Unsigned $n$-bit Integer $\langle\mathbb K\rangle_{Z+}(n)$
    - Signed Arbitrary Integer $\langle\mathbb K\rangle_{Z}(\infty)$
    - IEEE 754 Binary $n$-bit Float Number $\langle\mathbb K\rangle_{F}(n)$
    - IEEE 754 Decimal $n$-bit Float Number $\langle\mathbb K\rangle_{D}(n)$
    - Arbitrary Decimal $\langle\mathbb K\rangle_{D}(\infty)$

구체적인 매핑은 `./type-mapping`에 둔다.

## 3. 해상도 승격 (Promotion)
이 장에서 $Z(n)$, $Z^+(n)$, $F(n)$, $D(n)$, $D(\infty)$는 각각 $\langle\mathbb K\rangle_{Z}(n)$, $\langle\mathbb K\rangle_{Z+}(n)$, $\langle\mathbb K\rangle_{F}(n)$, $\langle\mathbb K\rangle_{D}(n)$, $\langle\mathbb K\rangle_{D}(\infty)$의 줄임이다.
스칼라 타입(체) $\mathbb K$와 해상도는 독립적으로 승격한다.

### 3.1. 체의 승격
이항 연산의 체는 두 피연산자 체의 상한(join)이다. 즉 $\mathrm{Real} \vee \mathrm{Complex} = \mathrm{Complex}$.

$\mathrm{Bool}$은 다른 체와 상한을 갖지 않으므로, $\mathrm{Bool}$과 $\mathrm{Real}$/$\mathrm{Complex}$ 사이의 연산은 타입 오류다.

### 3.2. 표현 순서
해상도 $A$의 모든 값을 해상도 $B$가 **정확히** 표현할 수 있을 때 $A \sqsubseteq B$로 쓴다.

| 관계 | 조건 |
| --- | --- |
| $Z(a) \sqsubseteq Z(b)$ | $a \le b$ |
| $Z^+(a) \sqsubseteq Z^+(b)$ | $a \le b$ |
| $Z^+(a) \sqsubseteq Z(b)$ | $a < b$ |
| $Z(a),\ Z^+(a) \sqsubseteq Z(\infty)$ | 항상 |
| $F(a) \sqsubseteq F(b)$ | $a \le b$ |
| $Z(a) \sqsubseteq F(b)$ | $a - 1 \le p(b)$ ($p(b)$: 가수 비트 수 + 1. $p(32)=24$, $p(64)=53$) |
| $Z^+(a) \sqsubseteq F(b)$ | $a \le p(b)$ |
| $D(a) \sqsubseteq D(b)$ | $a \le b$ |
| $Z(a) \sqsubseteq D(b)$ | $2^{a-1} \le 10^{q(b)}$ ($q(b)$: 십진 유효자릿수. $q(32)=7$, $q(64)=16$, $q(128)=34$) |
| $Z^+(a) \sqsubseteq D(b)$ | $2^{a} \le 10^{q(b)}$ |
| $Z(\infty),\ F(a),\ D(a) \sqsubseteq D(\infty)$ | 항상 ($F$, $D(a)$의 NaN, $\pm\infty$ 제외) |

$Z(a) \sqsubseteq Z^+(b)$는 성립하지 않는다. 이진 부동소수와 십진 부동소수 사이($F(a)$와 $D(b)$)도 서로 정확히 표현하지 못하므로 $\sqsubseteq$가 성립하지 않는다.

$\sqsubseteq$는 **암시적 변환이 허용되는 방향**이다. 대입·인자 전달에서 $\sqsubseteq$를 만족하지 않는 변환은 명시적 변환을 요구한다.

### 3.3. 이항 산술 연산의 결과 해상도
피연산자 해상도 $A$, $B$에 대해 결과 해상도 $A \sqcup B$는 아래 표에서 **위에서부터 처음 맞는 행**으로 정한다.

| # | 조건 | 결과 |
| --- | --- | --- |
| 1 | 어느 한쪽이 $D(\infty)$ | $D(\infty)$ |
| 2 | 한쪽이 $Z(\infty)$, 다른 쪽이 $F$ 또는 $D(n)$ | $D(\infty)$ |
| 3 | 어느 한쪽이 $Z(\infty)$ | $Z(\infty)$ |
| 4 | 어느 한쪽이 $D(n)$ | $D(\max)$ — 양쪽 $D$, $F$의 너비 중 최댓값, 정수 쪽은 무시 |
| 5 | 어느 한쪽이 $F$ | $F(\max)$ — 양쪽 $F$의 너비 중 최댓값, 정수 쪽은 무시 |
| 6 | $Z(a)$, $Z(b)$ | $Z(\max(a, b))$ |
| 7 | $Z^+(a)$, $Z^+(b)$ | $Z^+(\max(a, b))$ |
| 8 | $Z(a)$, $Z^+(b)$ | $Z(\max(a, b + 1))$ |

규칙 4, 5는 정확성보다 성능을 택한 규칙이다. 부동소수는 정수와 섞이면 더 높은 너비의 부동소수로 변환한다.
- 예: $Z(64) \sqcup F(32) = F(32)$이며, 정밀도 손실이 있을 수 있다. 이는 Java의 이진 수치 승격과 같다.
- 십진 부동소수 $D(n)$도 같은 방식으로 승격하며, 이진 부동소수와 섞이면 십진 쪽을 따른다. 예: $D(32) \sqcup F(64) = D(64)$

#### 최소 연산 폭
정수 결과(규칙 6–8)의 폭은 최소 32비트로 올린다. 즉 $Z(8) + Z(8) = Z(32)$.

- 바이트·문자 데이터를 누적할 때 생기는 의도치 않은 오버플로를 줄인다.
- Java의 정수 승격 규칙과 일치하므로 생성 코드에 축소 변환(cast)이 필요 없다.

#### 연산자별 예외
| 연산 | 결과 |
| --- | --- |
| 단항 $-$ on $Z^+(n)$ | $Z(n+1)$ (최소 연산 폭 적용) |
| $Z^+(a) - Z^+(b)$ | $Z(\max(a, b) + 1)$ (최소 연산 폭 적용) |
| 정수 $/$ 정수 | $F(64)$ (참 나눗셈). $Z(\infty)$가 포함되면 $D(\infty)$ |
| `//` (내림 몫) | $-\infty$ 방향으로 내린 몫(Python `//`, Java `Math.floorDiv`와 같음). 해상도는 $\sqcup$ 규칙을 따른다(정수끼리는 정수) |
| `///` (버림 몫) | 0 방향으로 버린 몫(Java 정수 `/`와 같음). 해상도는 $\sqcup$ 규칙 |
| $A$ `^` 음이 아닌 정수 리터럴 | $A$ (최소 연산 폭 적용) |
| $A$ `^` 그 외 | $A \sqcup F(64)$ |
| `%%` (내림 나머지) | 제수의 부호를 따른다(Python `%`, Java `Math.floorMod`와 같음). `a // b`와 짝을 이뤄 $a = (a\ /\!/\ b) \cdot b + (a \,\%\%\, b)$가 성립한다. $\sqcup$ 규칙 |
| `%%%` (버림 나머지) | 피제수의 부호를 따른다(Java `%`와 같음). `a /// b`와 짝을 이뤄 $a = (a\ /\!/\!/\ b) \cdot b + (a \,\%\%\%\, b)$가 성립한다. $\sqcup$ 규칙 |

몫과 나머지는 기호의 개수로 반올림 방향을 나타낸다. 기호가 2개(`//`, `%%`)면 $-\infty$ 방향(내림), 3개(`///`, `%%%`)면 0 방향(버림)이다. 기호 1개인 `%`는 없다. Java의 `a % b`는 VEL에서 `a %%% b`로 쓴다.

| | `a // b` | `a %% b` | `a /// b` | `a %%% b` |
| --- | --- | --- | --- | --- |
| $a = -7,\ b = 2$ | $-4$ | $1$ | $-3$ | $-1$ |
| $a = 7,\ b = -2$ | $-4$ | $-1$ | $-3$ | $1$ |

#### 성분별 연산과 행렬 연산
성분별 연산자는 대응하는 연산자와 같은 해상도 규칙을 원소마다 적용한다.

| 성분별 | 따르는 규칙 |
| --- | --- |
| `.+` `.-` | `+` `-` (별칭) |
| `.*` | `*` |
| `./` | `/` |
| `.^` | `^` |

`//`, `///`, `%%`, `%%%`는 행렬에 대해 원래 원소별로 동작한다.

행렬 연산의 결과 원소 해상도는 다음과 같다.
- **`*` (행렬 곱)**: 원소의 곱과 합만으로 계산하므로 두 원소 해상도의 $\sqcup$를 따른다.
- **`/` (우측 나눗셈, $A/B = AB^{-1}$)**: $B$가 스칼라가 아니면 역행렬이 필요하다. 그래서 $A \sqcup B$에 **정수 $/$ 정수** 규칙을 적용한다.
  - 정수 → $F(64)$
  - $Z(\infty)$ 포함 → $D(\infty)$
  - $F$, $D(\infty)$ → 그대로
  - $D(\infty)$의 역행렬은 사칙연산만으로 구하므로 분수 표현으로 정확하게 계산한다.
- **`^` (행렬 거듭제곱)**: 스칼라 `^`와 같다.
  - 음이 아닌 정수 리터럴 지수는 반복 곱이므로 해상도를 유지한다.
  - 그 외 지수(음의 지수는 역행렬을 포함)는 $A \sqcup F(64)$다.
- **`'`, `.'` (전치)**: 해상도를 바꾸지 않는다.

#### 오버플로
고정 폭 정수 $Z(n)$, $Z^+(n)$의 연산 결과가 범위를 넘으면 2의 보수로 순환(wrap)한다.

#### $D(\infty)$의 정밀도
$D(\infty)$는 **중간 연산에서 반올림 오차를 최대한 누적하지 않고**, **최종 결과에서 필요할 때만 한 번 반올림**한다.

**중간 연산**
- $+$, $-$, $\times$, 정수 지수 거듭제곱: 유한 십진수끼리의 연산이므로 그대로 정확하다.
- $/$: 즉시 반올림하지 않는다. 값을 분수 $p/q$($p, q$는 $D(\infty)$, $q > 0$)로 유지하고, 이후 연산도 분수 연산으로 이어간다.
  - 예: $a/b + c/d = (ad + cb)/(bd)$
  - 이렇게 하면 나눗셈은 최종 결과에서 한 번만 일어난다.
- 비교: 분수끼리 교차 곱으로 비교하므로 반올림 없이 정확하다.
- 정확히 표현할 수 없는 연산(정수가 아닌 지수, 이후 추가될 $\sqrt{\ }$·초월 함수 등): 중간 반올림이 불가피하다.
  - 이때는 최종 정밀도보다 높은 **작업 정밀도**로 계산한다.
  - 중간 반올림이 일어나는 경우는 이것뿐이다.

값이 VEL 밖으로 나가는 시점을 최종 결과로 본다.

- Java 쪽 변수·필드에 대입
- 외부 함수의 인자로 전달
- 다른 해상도로 변환

VEL 내부 지역 변수에 대입하는 것은 중간 연산이다.

최종 결과에서는 다음과 같이 처리한다.
- 분수 $p/q$가 유한 십진수로 나누어떨어지면 **반올림 없이 정확한 값**을 낸다.
- 그렇지 않을 때만(예: $1/3$) **최종 정밀도 문맥**으로 반올림한다.

최종 정밀도 문맥과 작업 정밀도의 기본값은 대상 언어 매핑에서 정하며, 설정(`@VelConfig`)으로 바꿀 수 있다.

분수 표현은 연산이 이어질수록 분자·분모의 자릿수가 커질 수 있다. 반복 누적에서는 정확도를 얻는 대신 비용이 든다.

### 3.4. 리터럴
리터럴은 **미정 해상도**를 가지며, 함께 쓰인 피연산자의 해상도를 따른다.
- 정수 리터럴은 상대 해상도가 그 값을 정확히 표현할 수 있으면 그 해상도를 따른다. 예: `0.5 * x`에서 `x`가 $F(32)$이면 `0.5`도 $F(32)$.
- 소수 리터럴은 상대가 $F$ 또는 $D$일 때만 그 해상도를 따른다.
- 따를 상대가 없거나 표현할 수 없으면 기본 해상도를 쓴다.
  - 정수 리터럴: $Z(32)$, 범위를 넘으면 $Z(64)$, 그것도 넘으면 $Z(\infty)$
  - 소수 리터럴: $F(64)$

### 3.5. 배열
배열 간 원소별 연산의 원소 해상도는 위 규칙을 원소 해상도에 적용해 정한다.
$$ \mathrm{Array}(\mathbf d, \langle\mathbb K_1\rangle_A) \circ \mathrm{Array}(\mathbf d, \langle\mathbb K_2\rangle_B) : \mathrm{Array}(\mathbf d, \langle\mathbb K_1 \vee \mathbb K_2\rangle_{A \sqcup B}) $$

[^1]: 엄밀히 수학적으로는 체(field)가 아니지만 VEL에서는 스칼라 타입으로 취급한다. Boolean 체에서는 $+$ 연산을 OR로, $\cdot$ 연산을 AND로 적용한다.
