# VEL 문법
VEL(Vector Expression Language)의 문법을 정리한다. 원본 문법은 `vel-core/src/main/antlr/com/doubledeltas/vel/parser/Vel.g4`이며, 타입과 연산의 의미는 [VEL 타입 시스템](./type-system.md)에 둔다.

## 1. 사용 위치
VEL 코드는 Java/Kotlin 소스 안의 문자열로 쓴다.

| 형태 | 예 | 진입 규칙 | 내용 |
| --- | --- | --- | --- |
| 메서드 본문 | `@Vel("...")` 추상 메서드 | `program` | 문장 여러 개 |
| 인라인 식 | `vel("...")` | `singleExpression` | 식 하나 |

```java
public interface Physics {
    @Vel("""
        # constant-acceleration step
        return p + v * dt + 0.5 * a * dt^2
        """)
    double position(double p, double v, double a, double dt);

    default double kineticEnergy(double m, double v) {
        return vel("0.5 * m * v^2");
    }
}
```

VEL 코드는 Java/Kotlin 문자열 리터럴이므로 그 언어의 이스케이프 규칙이 먼저 적용된다. Kotlin 문자열 안의 `$`는 템플릿으로 해석되므로 `${'$'}`로 쓴다.

## 2. 어휘 구조
### 2.1. 공백과 줄바꿈
공백과 탭은 토큰 사이를 구분할 뿐 의미가 없다.

**줄바꿈은 문장 구분자**다. 단, 다음 경우의 줄바꿈은 무시하고 다음 줄로 이어 쓴다.
- `(` 또는 `[` 안
- 줄이 이항 연산자, 대입 연산자, `,`, `:`, `.`, `if`, `then`, `else`로 끝난 경우
- 조건식에서 `then`, `else` 앞의 줄바꿈

```
m = [1, 2;
     3, 4]          # [ ] 안의 줄바꿈
x = a +
    b               # + 뒤의 줄바꿈
```

### 2.2. 주석
| 형태 | 설명 |
| --- | --- |
| `# ...` | 줄 끝까지 주석 |
| `/* ... */` | 블록 주석. 여러 줄에 걸치면 줄바꿈 하나로 취급한다. |

`//`, `///`는 몫 연산자이므로 주석이 아니다.

### 2.3. 식별자
식별자는 **Java 식별자와 같은 문자 집합**을 쓴다(`Character.isJavaIdentifierStart`, `isJavaIdentifierPart`). 유니코드 문자, `$`, `_`를 쓸 수 있다. 그래서 Java/Kotlin의 지역 변수, 매개변수, 필드를 이름 그대로 참조할 수 있다.

```
θ * 속도 + a$b_1 + $x
```

**백틱 식별자** `` `이름` ``는 미리 선언된 이름(2.5절)을 거치지 않고 같은 이름의 Java/Kotlin 변수를 가리킨다. 백틱 안에는 Java 식별자만 쓸 수 있다.

```
j      # 허수 단위
`j`    # Java 변수 j
```

### 2.4. 예약어
예약어는 다음 여섯 개다.

`return` `true` `false` `if` `then` `else`

`then`을 뺀 다섯 개는 Java와 Kotlin의 예약어이기도 하다. `then`이라는 이름의 Java/Kotlin 변수는 `` `then` ``처럼 백틱으로 쓴다.

### 2.5. 미리 선언된 이름
다음 이름은 예약어가 아니라 **미리 선언된 변수**다. 대입하면 다른 변수처럼 새 값에 다시 묶인다. 같은 이름의 Java 변수는 백틱으로 쓴다.

| 이름 | 의미 |
| --- | --- |
| `j` | 허수 단위 $\mathrm{complex}(0, 1)$ |
| `end` | 인덱스 안에서 그 차원의 **길이**(마지막 인덱스는 `end-1`) |

내장 함수(예: `abs`)의 이름도 미리 선언된 이름이다. 대입하면 가려진다. 예: `abs = Math.abs{double}` 뒤의 `abs(x)`는 Java의 `Math.abs(double)`을 부른다.

### 2.6. 리터럴
| 종류 | 예 | 설명 |
| --- | --- | --- |
| 정수 | `0`, `42`, `1_000` | 숫자 사이에 `_`를 넣을 수 있다. |
| 소수 | `0.5`, `.5`, `1e-3`, `2.5E10` | `.` 뒤에는 숫자가 반드시 와야 한다(`2.`는 불가). |
| Bool | `true`, `false` | |

`.` 뒤에 숫자가 필수이므로 `2.*x`는 `2 .* x`로 읽힌다(MATLAB과 같음). 리터럴은 정확한 수이며, 해상도는 구체화할 때 정해진다(타입 시스템 3.3절, Java 매핑 7.6절).

## 3. 프로그램과 문장
### 3.1. 프로그램
`@Vel` 본문은 줄바꿈이나 `;`로 구분한 문장의 나열이다.

- **식 하나로 된 프로그램은 그 식이 반환값이다.**
- 그 외에는 **마지막 문장이 `return`이어야 하며**, `return`은 마지막 문장으로만 쓸 수 있다.

```
p + v * dt                  # 식 하나: 그대로 반환
```
```
v2 = v + a * dt
return p + v2 * dt          # 여러 문장: return으로 끝남
```

인라인 `vel("...")`에는 식 하나만 쓸 수 있다(문장 불가).

### 3.2. 문장
| 문장 | 형태 |
| --- | --- |
| 반환 | `return` *식* |
| 대입 | *대상* *대입연산자* *식* |
| 구조 분해 대입 | *패턴* `=` *식* (3.3절) |
| 식 | *식* |

**대입 대상**은 변수, 또는 변수의 원소·부분행렬이다. 멤버 대입(`v.x = 1`)은 허용하지 않는다.

```
x = 1
m[0, 1] = 2
m[0:2, :] = B
v[end-1] += 1
```

VEL의 모든 값은 불변이며, 인덱스 대입은 **복사 후 다시 쓰기**다(타입 시스템 1.5절). `m[i] = x`는 `m`을 복사해 원소를 바꾼 새 값을 만들고 `m`을 그 값에 다시 묶는다. Java에서 넘겨받은 배열은 바뀌지 않는다.

**대입 연산자**

| 연산자 | 의미 |
| --- | --- |
| `=` | 대입 |
| `+=` `-=` `*=` `/=` `^=` | `x = x op y` |
| `//=` `///=` `%%=` `%%%=` | 몫·나머지 |
| `.+=` `.-=` `.*=` `./=` `.^=` | 성분별 연산 |
| `o+=` | Bool XOR |

### 3.3. 구조 분해 대입
튜플이나 행렬 리터럴 모양의 **패턴**에 값을 대입하면, 값을 앞 차원부터 나눠 패턴의 각 대상에 묶는다.

```
(x, y, z) = (1, 2, 3)        # x = 1, y = 2, z = 3
[a, b; c, d] = eye(2, 2)     # a = 1, b = 0, c = 0, d = 1
(m[0], `j`) = v              # 대상은 인덱스 대상이나 백틱 이름도 된다
(x, ?, z) = v                # ?: 그 자리의 원소를 버린다
(u, v) = M                   # M : Mat(2, n)이면 u, v는 각 행 (Vec(n))
```

- 튜플 패턴 `(t₁, …, tₖ)`(대상 2개 이상)은 첫 차원이 $k$인 값을 받고, 각 대상은 나머지 차원을 받는다. 튜플(4.2절)을 되돌린다.
- 행렬 패턴 `[t₁₁, …; …]`($r \times c$)은 앞의 두 차원이 $r \times c$인 값을 받고, 각 대상은 나머지 차원을 받는다. 행렬 패턴의 각 행은 대상 수가 같아야 한다.
- 각 대상은 일반 대입의 대상과 같다(변수, 원소·부분행렬). 같은 대상을 두 번 쓸 수 없다.
- `?`는 그 자리의 원소를 버린다. 어디에도 묶이지 않지만 모양 검사에는 포함된다(`(x, ?, z) = v`의 `v`는 여전히 첫 차원이 3). `?`는 여러 번 써도 되며, 패턴 밖에서는 쓸 수 없다.
- 크기가 정해진 값의 모양이 패턴과 다르면 컴파일 오류다. 크기가 $\top$이면 타입 시스템 1.2절을 따른다.
- 행렬 값을 행렬 패턴으로 분해하면 각 대상은 **원소 하나(스칼라)** 를 받는다. 블록 단위로 나눠 받으려면 오른쪽에 분할점을 쓴다(`[A, B; C, D] = M[0:2:3, 0:1:3]`, 4.8절).
- 대입 연산자는 `=`만 쓸 수 있다.

## 4. 식
### 4.1. 우선순위
위에서 아래로 우선순위가 낮아진다.

| 순위 | 연산 | 결합 |
| --- | --- | --- |
| 1 | 기본 항 (4.2절) | |
| 2 | 후위: 메서드 호출 `e.f(…)`, 원소별 메서드 호출 `e.f.(…)`, 멤버 `e.x`, 인덱스 `e[…]`, 전치 `e'` `e.'` | 왼쪽 |
| 3 | 거듭제곱 `^` `.^` | **오른쪽** |
| 4 | 단항 `-` `+` | 접두 |
| 5 | 곱셈 계열 `*` `/` `/>` `/<` `//` `///` `%%` `%%%` `.*` `./` | 왼쪽 |
| 6 | 덧셈 계열 `+` `-` `.+` `.-` `o+` | 왼쪽 |
| 7 | 범위 `:` | |
| 8 | 조건식 `if … then … else …` | |

예:
- `-a^2` = `-(a^2)`, `2^-1` = `2^(-1)`, `a^b^c` = `a^(b^c)`
- `a^b'` = `a^(b')`, `-v'` = `-(v')`
- `a o+ b * c` = `a o+ (b * c)`
- `a+1:b-1` = `(a+1):(b-1)`

### 4.2. 기본 항
| 형태 | 예 | 설명 |
| --- | --- | --- |
| 리터럴 | `3`, `0.5`, `true` | 2.6절 |
| 이름 | `x`, `` `j` `` | 2.3절 |
| 함수 호출 | `sqrt(x)`, `f()` | 내장 함수, 정적 임포트한 함수, 최상위 함수 |
| 원소별 적용 | `sqrt.(v)`, `f.(A, x)` | 함수를 원소마다 적용한다(아래) |
| 시그니처 지정 | `max{int, int}`, `f{double}(x)` | 오버로딩 중 하나를 고른다(4.3절) |
| 괄호 | `(a + b)` | |
| 튜플 | `(x, y, z)` | 항목을 쌓기. 스칼라면 열벡터, 벡터면 행렬(항목이 행) |
| 행렬 리터럴 | `[1, 2; 3, 4]` | `,`는 가로, `;`는 세로 연결 |

**행렬 리터럴**은 행 우선으로 쓴다. 원소가 행렬이면 블록 행렬이다.

```
[1, 2, 3]           # 1x3 행벡터
[1, 2; 3, 4]        # 2x2 행렬
[A, B; C, D]        # 블록 행렬: (a+b) x (c+d)
(x, y, z)           # 스칼라 튜플: 3x1 열벡터 = [x; y; z]
(u, v)              # 길이 n인 벡터 튜플: 2xn 행렬, u와 v가 각 행
```

**튜플**은 항목을 연결하지 않고 **쌓는다**. 항목의 모양은 모두 같아야 하며, 결과는 항목 수만큼의 차원이 앞에 붙은 배열이다(타입 시스템 1.4절). Java `record`와 Kotlin `Pair` 같은 성분 객체도 같은 규칙으로 배열이 된다.

원소는 반드시 `,`로 구분한다. MATLAB처럼 공백으로 구분하는 표기(`[A B]`)는 쓰지 않는다. `(x)`는 괄호이며, 원소 하나짜리 튜플은 없다.

**원소별 적용** `f.(x)`는 함수 `f`를 배열의 원소마다 적용한다(Julia와 같음, 타입 시스템 1.9절). `.*`, `.^`처럼 점은 원소별을 뜻한다.
- `f(A)`와 `f.(A)`는 다르다. 예: `exp(A)`는 행렬 지수 함수이고, `exp.(A)`는 원소마다의 지수 함수다.
- 스칼라를 받는 함수에 배열을 넘기면(`sqrt(v)`) 오류다. 원소별 적용은 `sqrt.(v)`로 쓴다.
- 인자가 여럿이면 인자끼리 브로드캐스팅한다(타입 시스템 1.3절). 예: `f.(A, x)`에서 스칼라 `x`는 모든 원소에 쓰인다.
- 메서드에도 쓸 수 있다: `Math.sqrt.(v)`, `t.foo.(x)`
- 숫자 뒤의 `.`은 숫자의 일부가 아니므로(2.6절) `.(`는 이름이나 메서드 이름 뒤에만 온다.

```
y = sqrt.(v)              # 원소마다 제곱근
z = Math.max.(a, 0)       # 원소마다 max(a_i, 0)
E = exp.(A)               # 원소별 지수 (exp(A)는 행렬 지수)
```

### 4.3. 후위 연산
| 형태 | 설명 |
| --- | --- |
| `t.foo(x)` | 동적 메서드 호출. `foo(t, x)`로는 부를 수 없다. |
| `t.foo.(x)`, `T.foo.(x)` | 메서드의 원소별 적용(4.2절) |
| `T.foo{double}`, `t.foo{int, int}(x)` | **시그니처 지정**: 매개변수 타입을 타깃 언어의 타입으로 써서 오버로딩 중 하나를 고른다. 호출 없이 쓰면 함수 값이다(Java 매핑 3.1절). |
| `T.foo(x)` | 정적 메서드 호출(`java.lang.Math.sqrt(x)`처럼 정규화된 이름도 가능) |
| `t.x` | 필드(Kotlin은 속성) 접근 |
| `m[…]` | 인덱싱 (4.6절) |
| `a'` | 켤레 전치 |
| `a.'` | 전치 (실수 값에서는 `'`와 같다) |

랭크 3 이상의 배열을 전치하면 인덱스 순서가 뒤집힌다.

### 4.4. 산술 연산자
VEL은 MATLAB처럼 **행렬 연산자**와 **성분별 연산자**를 구분한다.

| 행렬 | 의미 | 성분별 |
| --- | --- | --- |
| `*` | 행렬 곱 (스칼라와는 원소별 곱) | `.*` |
| `/`, `/>` | 우측 나눗셈 $AB^{-1}$ (스칼라끼리는 참 나눗셈) | `./` |
| `/<` | 좌측 나눗셈 $A^{-1}B$ | |
| `^` | 행렬 거듭제곱 (지수는 스칼라만) | `.^` |
| `+` `-` | 덧셈, 뺄셈 (원래 성분별) | `.+` `.-` (별칭) |

- 정사각 행렬끼리의 `*`는 행렬 곱이다. 원소별 곱은 `.*`로 쓴다.
- `/`, `/>`, `/<`의 제수는 정사각(가역) 행렬이어야 한다.
- 행렬 지수 함수 $e^A$는 연산자가 아니라 이후 `exp(A)` 함수로 제공한다.
- 단항 `-`, `+`가 있다. 단항 `.-`는 없다.

### 4.5. 몫과 나머지
몫과 나머지는 **기호의 개수로 반올림 방향**을 나타낸다. 모두 원소별 연산이다.

| 반올림 방향 | 몫 | 나머지 | 같은 연산 |
| --- | --- | --- | --- |
| 없음 | `/` (참 나눗셈) | — | |
| $-\infty$ (내림) | `//` | `%%` | Python `//` `%`, Java `Math.floorDiv` `Math.floorMod` |
| 0 (버림) | `///` | `%%%` | Java 정수 `/` `%` |

| | `a // b` | `a %% b` | `a /// b` | `a %%% b` |
| --- | --- | --- | --- | --- |
| $a = -7,\ b = 2$ | $-4$ | $1$ | $-3$ | $-1$ |
| $a = 7,\ b = -2$ | $-4$ | $-1$ | $-3$ | $1$ |

기호 하나인 `%`는 없다. Java의 `a % b`는 `a %%% b`, 정수 `a / b`는 `a /// b`로 옮긴다.

### 4.6. Bool 연산
| 연산자 | 의미 |
| --- | --- |
| `+` | OR |
| `*` | AND |
| `o+` | XOR ($\oplus$) |

`o+`는 덧셈과 같은 우선순위다. 렉서는 더 긴 토큰을 우선하므로, 이름이 `o`인 변수 바로 뒤에 `+`를 붙이면(`o+1`) XOR로 읽힌다. 이때는 `o + 1`처럼 띄우거나 `` `o`+1 ``로 쓴다.

### 4.7. 범위와 인덱싱
**범위** `a:b`는 Python과 같이 **끝을 포함하지 않는** 구간 $[a, b)$의 인덱스다. 길이는 $b - a$이며, $b < a$면 길이가 $\bot$(null)이라 쓰면 오류다(타입 시스템 1.1절, 1.6절). 빈 범위는 `a:a`로 쓴다.
- 경계는 서수다. `int` 같은 정수 값도 쓸 수 있으며, 음수는 $\bot$(null)이 된다. `end`는 그 차원의 길이이므로 `a:end`는 끝까지다.
- 증분 형태는 없다. VEL은 MATLAB과 다른 표기를 쓴다.

**인덱싱** `m[s₁, …, sₖ]`의 각 첨자는 다음 중 하나다. 인덱스는 0부터 시작한다.

| 첨자 | 예 | 선택 |
| --- | --- | --- |
| 정수 | `m[1, 2]` | 한 위치 |
| 범위 | `m[0:2, :]` | $[0, 2)$의 각 위치 |
| 분할점 | `m[0:2:3, :]` | 블록 $[0, 2)$, $[2, 3)$ (4.8절) |
| `:` | `m[:, j]` | 차원 전체 |

- 첨자의 개수는 배열의 랭크와 같아야 한다. 벡터는 첨자 하나로 인덱싱할 수 있다(`v[end-1]`: 마지막 원소).
- `end`와 `:`는 인덱스 안에서만 쓴다.

```
m[1, :]         # 1번 행
m[:, 0:2]       # 0~1번 열
v[1:end]        # 첫 원소를 뺀 나머지
v[end-1]        # 마지막 원소
```

### 4.8. 분할과 블록 분해
첨자 자리에 **분할점** `a₀:a₁:…:aₖ`(점 3개 이상)를 쓰면 그 차원을 블록 $[a_0, a_1), [a_1, a_2), \cdots, [a_{k-1}, a_k)$로 나눈다. 분할점은 0 이상이고 순증가하며, 마지막 점은 차원의 크기를 넘을 수 없다. 마지막 점을 `end`로 쓰면 차원 끝까지다(예: `M[0:2:end, :]`). 범위 `a:b`는 블록이 하나인 분할과 같다.

분할한 인덱싱은 **블록 행렬(행렬의 행렬)** 이며, 구조 분해 대입으로 블록마다 나눠 받을 수 있다.

```
M = [1, 2, 3; 4, 5, 6; 7, 8, 9]
[A, B; C, D] = M[0:2:3, 0:1:3]
# A = [1; 4], B = [2, 3; 5, 6], C = 7, D = [8, 9]
```

- 행렬 패턴은 (행 블록 수) × (열 블록 수)여야 한다. 행만 분할했다면 튜플 패턴으로 받는다. 예: `(Top, Bottom) = M[0:3:6, :]`
- 분할점이 리터럴이면 각 대상은 자기 블록의 정확한 크기를 받는다. 위 예에서 `A`는 $2 \times 1$, `C`는 스칼라다.
- `?`는 블록 하나를 버린다.

분할한 인덱싱을 변수 하나에 대입하면 블록을 쌓은 3차원 또는 4차원 배열(블록 텐서)이 된다(타입 시스템 1.7절). 블록 번호가 앞 차원이다.

```
T = M6[0:2:4:6, 0:3:6]     # T : Array(3, 2, 2, 3), 블록 (i, j)는 T[i, j, :, :]
R = M6[0:2:4:6, :]         # R : Array(3, 2, 6),    블록 i는 R[i, :, :]
```

분할점 체인은 첨자 자리에서만 쓸 수 있다. `x = 0:1:3`이나 `f(0:1:3)`은 오류다. 분할한 인덱스에 대입(`M[0:2:3, :] = …`)할 수는 없다.

### 4.9. 조건식
`if` *조건* `then` *값* `else` *값*은 조건에 따라 두 값 중 하나가 되는 **식**이다.

```
s = if x then 1 else -1
y = if c1 then a else if c2 then b else d      # else if로 이어 쓴다
```

- 조건은 `Bool` 스칼라다. 고른 쪽 가지만 평가한다.
- 결과 타입은 두 가지의 공통 타입이다(타입 시스템 1.8절). 두 가지의 모양이 맞아야 한다.
- `else`는 반드시 있어야 한다.
- 우선순위가 가장 낮아서 `else` 뒤는 끝까지 이어진다. `if c then a else b + 1`은 `if c then a else (b + 1)`이다. 다른 식의 피연산자로 쓸 때는 괄호로 감싼다: `x * (if c then 2 else 3)`
- 여러 줄로 쓸 수 있다.

```
y = if c
    then a
    else b
```

## 5. 문법 요약
`Vel.g4`의 파서 규칙을 줄여 적는다. `"..."`는 토큰이다.

```
program          = sep* (statement (sep+ statement)*)? sep* EOF
singleExpression = NEWLINE* expr NEWLINE* EOF
sep              = NEWLINE | ";"

statement = "return" expr
          | pattern "=" expr
          | target assignOp expr
          | expr
target    = name ("[" indexList "]")?
pattern   = "(" patternItem ("," patternItem)+ ")"
          | "[" patternRow (";" patternRow)* "]"
patternRow  = patternItem ("," patternItem)*
patternItem = target | "?"
assignOp  = "=" | "+=" | "-=" | "*=" | "/=" | "//=" | "///=" | "%%=" | "%%%=" | "^="
          | ".+=" | ".-=" | ".*=" | "./=" | ".^=" | "o+="

expr = primary
     | expr "." ID signature? "(" arguments? ")"
     | expr "." ID signature? "." "(" arguments? ")"
     | expr "." ID signature
     | expr "." ID
     | expr "[" indexList "]"
     | expr ("'" | ".'")
     | expr ("^" | ".^") expr                                   (오른쪽 결합)
     | ("-" | "+") expr
     | expr ("*" | "/" | "/>" | "/<" | "//" | "///" | "%%" | "%%%" | ".*" | "./") expr
     | expr ("+" | "-" | ".+" | ".-" | "o+") expr
     | expr ":" expr
     | "if" expr NEWLINE* "then" expr NEWLINE* "else" expr

primary   = NUMBER | "true" | "false"
          | name signature? "(" arguments? ")"
          | name signature? "." "(" arguments? ")"
          | name signature
          | name
          | "(" expr ")"
          | "(" expr ("," expr)+ ")"
          | "[" matrixRow (";" matrixRow)* "]"
matrixRow = expr ("," expr)*
arguments = expr ("," expr)*
signature = "{" (typeName ("," typeName)*)? "}"
typeName  = name ("." name)* ("[" "]")*
indexList = index ("," index)*
index     = ":" | expr
name      = ID | QUOTED_ID
```

- 분할점 체인(`a:b:c…`)은 첨자 자리에서만 허용
- 3.1절의 반환 규칙
